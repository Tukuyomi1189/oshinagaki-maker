# お品書きメーカー

同人誌即売会の「お品書き」を作るためのブラウザツールです。サークル情報と頒布物を入力すると自動でレイアウトされ、PNG・PSD・Illustrator 用スクリプト（編集可能なデータ）を書き出せます。

- **オンライン版**：https://tukuyomi1189.github.io/oshinagaki-maker/ （ブラウザで開くだけで使えます）
- 単体の HTML ファイル 1 つで動作（ダウンロードすればオフラインでも使用可）
- 入力内容はブラウザ内に自動保存
- 1 枚構成と、種別ごとに振り分ける 2 枚構成に対応

## 動作環境

| 用途 | 必要なもの |
| --- | --- |
| 編集・PNG / PSD 書き出し | Chrome / Edge などの現行ブラウザ |
| 編集可能データの生成 | Adobe Illustrator（.jsx スクリプトを実行） |
| 画像の加工・入稿 | Photoshop / InDesign など（任意） |

## 使い方

### 1. 開く

次のどちらかで開きます。

- **オンライン**：https://tukuyomi1189.github.io/oshinagaki-maker/ を開く
- **ローカル**：`oshinagaki-maker.html` をダウンロードし、ダブルクリックしてブラウザで開く

入力内容や画像はブラウザの中だけで処理され、どこにも送信されません。自動保存はブラウザごとに別なので、オンライン版とローカル版、別の PC の間でデータを移すときは「プロジェクト保存」の JSON を使ってください。初回はサンプルが入っています。右上の「新規」を 2 回押すと空の状態になります。

操作方法は、右上の「？ ヘルプ」（または F1 キー）でいつでも確認できます。

### 2. 基本情報を入力する（基本情報タブ）

サークル名、スペース番号、ペンネーム、イベント名、日付、お支払い方法、SNS / 連絡先、お知らせを入力します。空欄の項目は表示されません。

### 3. 頒布物を登録する（頒布物タブ）

「＋ 追加」で 1 点ずつ登録します。

| 項目 | 内容 |
| --- | --- |
| 種別 | 初期は 新刊 / 準新刊 / セット / 既刊 / 委託 / グッズ（デザインタブで追加・変更できます） |
| 価格 | 数字は「¥500」形式に整形。0 は「無料」。文字を入れるとそのまま表示 |
| タイトル | 2 行まで表示（長い場合は省略記号） |
| 仕様 | 例：`B5 / 36P / 全年齢` |
| 説明 | カードに余白がある分だけ表示 |
| フラグ | R18 / 残りわずか / 完売（完売はカード全体に重ねて表示） |
| 画像 | 表紙画像（PNG / JPG / PSD・PSB） |
| 載せるページ | 2 枚構成のときの個別指定 |

各項目の ↑ ↓ で並べ替え、「複製」「削除」ができます。

### 4. デザインを決める（デザインタブ）

- **用紙**：A4・A3・B4・B5 の縦横、A5 横（卓上 POP）、SNS 用（16:9 / 4:3 / 正方形 / 4:5）
- **配置**：列数（新刊とそれ以外で別指定）、種別ごとの見出し、新刊を大きく、説明文の表示
- **種別**：種別の追加、名前の変更、色（バッジと見出し）、並べ替え（見出しの順番）、削除（その種別の頒布物は「既刊」に移る）
- **テーマ**：6 種類（和・藍朱 / さくら / 夜空 / モノクロ＋赤 / ミント / ポップ）。帯色とアクセント色は上書き可能
- **箱の色**：「箱の色を上書きする」をオンにすると、すべての箱の色と、枠線・区切り線の色を変えられます（新刊の枠線はアクセント色）。箱を 1 つだけ変えるときは、プロパティパネルで箱を選んで「箱」の色を指定します
- **箱のデザイン**：標準（角丸）/ 角なし / 影付き / 二重線 / 見出し帯 / 左ライン / 角飾り / 点線 / 透過素材 から選択。種別ごとに別のデザインにもできます（詳しくは「箱のデザイン」の節）
- **フォント**：ゴシック / 明朝 / 丸ゴシック。PC 内のフォント名を直接指定することもできます

変更は右側のプレビューにすぐ反映されます。

### 5. 書き出す（書き出しタブ）

PNG、PSD、または Illustrator 用スクリプトを書き出します。詳細は「書き出し」の節を参照してください。

## 箱を手動で調整する

自動レイアウトのあと、プレビュー上で箱（頒布物のカードと種別の見出し）を直接動かせます。

| 操作 | 動作 |
| --- | --- |
| 箱をドラッグ | 移動 |
| 辺をドラッグ（上下左右） | その方向だけ伸縮（中の文字と画像も追従） |
| 角をドラッグ（四隅） | 縦横同時に伸縮 |
| 矢印キー | 選択中の箱を 1mm 移動 |
| Shift＋矢印キー | 選択中の箱の大きさを変更 |
| Ctrl 併用 | 0.5mm 刻み |
| Shift＋辺・角をドラッグ | 中心を保ったまま大きさ変更（左右・上下に均等に伸縮） |
| Alt を押しながらドラッグ | 吸着と目安線を無効にする |
| 揃えボタン（画面下） | 選択中の箱を 左揃え / 左右中央 / 右揃え / 幅いっぱい にする |
| 「位置を戻す」（画面下）／「位置だけ戻す」（プロパティパネル） | 大きさはそのままで、位置だけ自動配置の場所に戻す |
| ダブルクリック / Delete | その箱だけ自動配置に戻す（位置も大きさも） |
| 用紙の外（灰色の部分）をクリック・タップ | 箱の選択を外す |

- ドラッグ中は、ほかの箱の端・中心や用紙の中央・余白に吸着し、ピンクの目安線が出ます
- デザインタブの「目安線を常に表示」で、余白と中央の線（水色）を出しっぱなしにできます。書き出しには出ません
- デザインタブの「プロパティパネルを表示」をオンにすると、選択中の箱の名前と X / Y / W / H（mm、用紙の左上が原点）が右上に出ます。数値を直接入力でき、箱の下にも大きさが表示されます。パネル右上の「×」で閉じられます（再表示はデザインタブから）
- プロパティパネル右上の「▾」で折りたたむと、箱の名前だけの 1 行になります。スマホではこの設定に関係なく、箱をタップすると画面下からシートで表示されます。「×」で箱の選択を外して閉じます（箱を選んでいないときは、画面下に操作のヒントが出ます）
- 動かしていない箱は自動配置のままです
- デザインタブの「すべて自動配置に戻す」で一括リセットできます
- 用紙サイズを変えると手動配置はリセットされます
- 手動配置は PNG・Illustrator 書き出しとプロジェクト保存にも反映されます

## 元に戻す／やり直し

| 操作 | 動作 |
| --- | --- |
| 「↶ 戻す」（画面下）／ Ctrl＋Z | 1 つ前の状態に戻す |
| 「↷ やり直し」（画面下）／ Ctrl＋Y（Ctrl＋Shift＋Z） | 戻した操作をやり直す |

- 箱の移動・伸縮だけでなく、文字の入力、頒布物の追加・削除・並べ替え、テーマや用紙の変更、「新規」「サンプル」「開く」なども戻せます（最大 100 手）
- 文字の入力は同じ欄への続けての入力をまとめて 1 手、ドラッグは 1 回分を 1 手として扱います
- 入力欄の中で Ctrl＋Z を押したときも、ツール全体の「元に戻す」になります
- 履歴はページを開いている間だけです（再読み込みで消えます）

## 確認モードと調整モード（スマホ向け）

| 操作 | 動作 |
| --- | --- |
| 右上の「確認」 | 入力パネルを隠してプレビューを画面いっぱいに表示（確認モード中は箱を動かせない） |
| 「調整に戻る」／ Esc | 入力パネルを戻して編集できる状態に戻す |
| 境目のつまみをドラッグ（スマホ） | プレビューと入力パネルの比率を変える。初期値は プレビュー 1：入力パネル 3。ダブルタップで 1:3 に戻る |

- 画面幅が 760px 以下（スマホなど）では、上がプレビュー、下が入力パネルになります
- モードと境目の位置はブラウザに記憶されます（プロジェクトの JSON には含まれません）

## 文字を調整する（文字タブ）

### 好きな場所に文字を入れる（自由テキスト）

1. 文字タブの「＋ 文字を追加」を押す
2. 文字の内容（改行可）、大きさ（mm）、色、濃さ、太字、揃え、ページを指定する
3. プレビュー上でドラッグして好きな場所に置く（矢印キー・目安線・揃えボタンも使えます）

ダブルクリックすると初期位置（用紙中央あたり）に戻ります。用紙サイズを変えたときも初期位置に戻ります。

### 文字サイズ・色・濃さ

| 対象 | 場所 | 内容 |
| --- | --- | --- |
| 文字サイズ | 文字タブ「文字サイズ（％）」 | タイトル / 価格 / 仕様・説明 / サークル名 / 種別の見出し を 50〜200% で調整 |
| 色と濃さ（種類ごと） | 文字タブ「文字の色と濃さ」 | サークル名、イベント名・日付、ペンネーム、スペース番号、種別の見出し、バッジ、タイトル、仕様、説明、価格、フッター、SNS のそれぞれに色と濃さ（0〜100％）を指定 |
| 箱ごとの文字と箱の色 | プロパティパネル | 箱を選び「字」（％）・「色」・「濃」（％）・「箱」（箱の色）を指定。その箱だけに適用 |

- 濃さは 100％が通常で、下げるほど薄く（半透明に）なります
- 色を変えていない項目はテーマの色に従います。「戻」ボタンで色だけテーマ色に戻せます
- 文字サイズと濃さは、全体の設定と箱ごとの設定の掛け算になります
- 箱ごとの色は、その箱のタイトル・仕様・説明に適用されます（価格とバッジは種類ごとの色のまま）
- 文字を大きくしすぎると箱からはみ出します。箱を広げるか倍率を下げてください

## 箱のデザイン

デザインタブ「箱のデザイン」で、頒布物の箱の見た目を変えられます。

| デザイン | 見た目 |
| --- | --- |
| 標準（角丸） | 角丸の細い枠（これまでの形） |
| 角なし | 角の丸みなし |
| 影付き（ポップ） | 太めの枠と、右下にずらした影 |
| 二重線 | 内側にもう1本の線 |
| 見出し帯 | 上辺に種別の色の帯 |
| 左ライン | 左辺に種別の色の太い線 |
| 角飾り（和風） | 四隅に種別の色の L 字飾り |
| 点線（チケット風） | 点線の枠 |
| 透過素材 | 読み込んだ透過 PNG を枠として使う |

- 「全体のデザイン」で全部の箱を、「種別ごとに変える」でその種別の箱だけを変えます（例：新刊だけ見出し帯）
- 色は種別の色・テーマの色に合わせて自動で決まります
- 透過素材は、四隅の形を保ったまま辺と中央だけを伸ばして箱に合わせます（9 スライス）
  - **素材の角の範囲 ％**：素材の短い辺のうち、角として扱う割合
  - **角の大きさ**：箱に描く角の大きさ
  - **素材の濃さ ％**：下げると素材が淡くなる（Illustrator では不透明度として入る）
  - **素材の下に箱の色を塗る**：オフにすると素材だけを描きます
- Illustrator 用スクリプトでは、透過素材は箱の大きさに引き伸ばして配置されます。素材のファイルも表紙画像と同じフォルダに置いてください
- 透過素材以外のデザインは、外部の素材を使わずプログラムで描いています。配布素材を使うときは、同人誌・お品書きでの使用や加工が利用規約で認められているか確認してください

## 背景に画像を敷く

デザインタブ「背景画像」の「画像を選ぶ」で、好きな画像（PNG / JPG / PSD）を用紙全体の背景にできます。「外す」で解除します。

| 設定 | 内容 |
| --- | --- |
| 画像の濃さ ％ | 下げると画像が淡くなり、文字が読みやすくなる |
| 帯の濃さ ％ | 下げるとヘッダー・フッターの帯が半透明になり、背景が透ける |
| 箱の濃さ ％ | 下げると頒布物の箱が半透明になる（枠線と文字はそのまま） |

- 画像は縦横比を保ったまま用紙を覆い、はみ出す分は切り落とされます
- Illustrator に書き出す場合は、背景画像のファイルも表紙画像と同じフォルダに置いてください（クリッピングマスク付きで配置されます）

## 2 枚に分ける

1. デザインタブの「2 枚に分ける」をオンにする
2. 種別ごとに 1 枚目 / 2 枚目を選ぶ
   （初期値：新刊・準新刊・セット → 1 枚目、既刊・委託・グッズ → 2 枚目）
3. 例外にしたい頒布物は、その項目の「載せるページ」で個別に指定する
4. 画面下の「1 枚目 / 2 枚目」でプレビューを切り替える

## まとめて登録する

### 画像からまとめて追加

表紙画像を複数選ぶと、ファイル名をタイトルにして一括登録されます。登録される種別は、ボタンの下の「画像からまとめて追加するときの種別」で選べます（初期値は新刊）。

### CSV 読込 / 保存

列の順番は次のとおりです。1 行目が見出し行の場合は読み飛ばします。

```
種別,タイトル,価格,仕様,説明,R18,完売,残りわずか,画像ファイル名
新刊,サンプル本,500,B5 / 36P,説明文,,,,cover01.png
既刊,前回の本,400,A5 / 28P,,,1,,cover00.png
```

- 種別は名前（新刊、既刊など、デザインタブの「種別」にある名前）で書きます。一覧に無い名前は、その名前の種別として自動で追加されます。空欄は「既刊」になります
- フラグ列は `1` や `○` でオンになります
- 「CSV 保存」で出力したファイルがそのままひな形になります

## 書き出し

### PNG

| 解像度 | 用途 |
| --- | --- |
| 350dpi / 300dpi | 印刷用 |
| Web / SNS 用 | 長辺 2048px |

2 枚構成のときは 2 ファイル（`_p1` / `_p2`）が出力されます。

### PSD（Photoshop）

「PSD を書き出す」で、PNG と同じ解像度設定の PSD を出力します。

- 「要素ごとに別レイヤーにするもの」で、分けたい種類を選びます。チェックした種類は要素 1 つずつが別レイヤーになり、外した種類は「背景 / 装飾 / 画像 / テキスト / 最前面」にまとめられます

| チェック | 別レイヤーになるもの | レイヤー名の例 |
| --- | --- | --- |
| 文字（初期値オン） | サークル名、見出し、頒布物ごとのタイトル・仕様・説明・価格・バッジ、自由テキスト | `タイトル：本の名前` `価格：本の名前` `自由テキスト：…` |
| 箱・図形（初期値オン） | 頒布物の箱、バッジの地、見出しの飾り、スペース枠、完売の幕 | `箱：本の名前` `見出し：新刊` `スペース枠` |
| 表紙画像（初期値オン） | 表紙ごと | `表紙：本の名前` |
| 背景・帯（初期値オフ） | 背景色、背景画像、ヘッダー帯、フッター帯、ライン | `背景色` `ヘッダー帯` |

- 各レイヤーは中身のある範囲だけの大きさで作られ、重なり順は画面と同じです
- 文字は画像化（ラスター）されるため、移動・表示切替・色調整はできますが、Photoshop で打ち直すことはできません。文字を編集したい場合は Illustrator 用スクリプトを使ってください
- 2 枚構成のときは 2 ファイル（`_p1` / `_p2`）が出力されます
- A3・350dpi など大きいサイズは数十秒かかることがあります

### Illustrator 用スクリプト（.jsx）

1. 「Illustrator 用スクリプト (.jsx) を書き出す」を押す
2. Illustrator で **ファイル ＞ スクリプト ＞ その他のスクリプト…** から .jsx を選ぶ
3. 表紙画像の元ファイルがあるフォルダを選ぶ（ファイル名で照合してリンク配置）
4. 新規ドキュメントが作成されるので、調整して保存する

作成されるドキュメントの特徴：

- 文字はすべて編集可能なテキスト
- レイヤーは「背景 / 装飾 / 画像 / テキスト / 最前面」の 5 つ
- 2 枚構成のときはアートボードが 2 つ並ぶ
- 「CMYK ドキュメントで作る」をオンにすると印刷向けのカラーモードになる

フォントは、選んだ系統に合わせて源ノ角・小塚・游・ヒラギノなどを順に探します。確実に指定したい場合は、書き出しタブで PostScript 名（例：`SourceHanSansJP-Bold`）を入力してください。見つからない場合は Illustrator の既定フォントになります。

## 保存と読込

- 入力内容はブラウザ内に自動保存されます。画像が多いと容量の都合で画像だけ保存されないことがあります
- 確実に残すには右上の「プロジェクト保存」で JSON ファイルにし、「開く」で読み込みます
- イベントごとに JSON を残しておくと、次回は価格や完売フラグを直すだけで済みます

## 注意点

- 手動で動かせるのは頒布物のカード、種別の見出し、自由テキストです。ヘッダーとフッターは固定です
- 手動で動かした箱は、あとで頒布物を増減しても位置が変わりません。重なった場合は動かし直すか自動配置に戻してください
- 頒布物が多くて窮屈になると画面下に警告が出ます。列数を増やす、用紙を大きくする、2 枚に分ける、のいずれかで解消できます
- ブラウザと Illustrator では字幅が少し変わります。はみ出しは Illustrator 側で微調整してください
- 読み込める画像は PNG / JPG / PSD（PSB）です。CLIP や AI などは PNG / JPG に書き出してから使ってください
- PSD はレイヤーではなく「統合画像」を読みます。真っ白になる・読めない場合は、Photoshop の「互換性を優先」をオンにして保存し直してください
- PSD の対応範囲は 8bit / 16bit の RGB・CMYK・グレースケールです（32bit、Lab などは不可）。CMYK は簡易変換のため、プレビューと PNG では色が少し変わります（Illustrator へは元の PSD がそのままリンク配置されます）
- PSD の透明部分は不透明として扱われます
- Illustrator へ書き出す場合、表紙画像は 1 つのフォルダにまとめ、登録時とファイル名を変えないでください
- Illustrator 用スクリプトは実機の Illustrator では未検証です（模擬実行のみ）。初回はエラーが出ないか確認してください
- 書き出した PSD は別のPSD読み込みライブラリで開けることを確認していますが、実機の Photoshop では未検証です
