用紙

配置

中身に合わせる：表紙の枚数と段数に合わせて箱の高さを変えます（表紙が多い箱は高く、横長の写真だけの箱は低く）。表紙の多い箱を広く：さらに、表紙の多い箱は何列か使って横にも広げます。どちらも用紙に収まるよう、ほかの箱の大きさを調整します

種別

上から順に見出しが並びます（↑↓で入れ替え。頒布物タブで種別の見出しをドラッグしても入れ替えられます）。名前を変えると、見出し・バッジ・頒布物タブの選択肢・CSV に反映されます。色はその種別のバッジと見出しの色です（「戻」でテーマの色に戻す）。
初期の「新刊」は名前や色を変えても、強調表示（箱の枠）・「新刊を大きく」・新刊の列数がそのまま効きます。
種別を削除すると、その種別の頒布物は「既刊」に移ります。CSVで一覧に無い種別名を読み込むと、その名前の種別が自動で追加されます。

種別ごとの並べ方

画像だけをオンにすると、その種別は表紙だけを並べ、価格は見出しの右のまとめ価格で示します（数字なら「ALL ¥500」、文字ならそのまま）。タイトルもで表紙の下に小さくタイトルを出します。表紙のない頒布物はタイトルの札になります。
上の種別の横に並べるをオンにすると、その種別を1つ上の種別の右に並べます（見出しごと。続けてオンにすれば3つ以上も並びます）。幅は箱の数で分けるので、並んだ箱は同じ幅になります。点数の少ない種別をまとめたいときに。

委託

頒布物タブの委託元にサークル名・作家名を入れると、その種別の中で「委託：〇〇」の小見出しごとに分かれます。種別が「委託」の頒布物と、委託元が入っている頒布物を委託として扱い、目立たせるがオンなら種別の色の枠とうっすらした色にします（ほかの種別なら「委託」のバッジも付けます）。

箱の手動調整

プレビュー上で箱をドラッグして移動、辺や角をドラッグして大きさ変更（上下左右の辺はその方向だけ、角は縦横同時）（中の文字も追従）。見出しも動かせます。
ドラッグ中は、ほかの箱の端・中心や用紙の中央・余白に吸着し、ピンクの目安線が出ます（Altで無効）。Shiftを押しながら辺や角をドラッグすると、中心を保ったまま大きさが変わります。箱を選ぶと画面下に揃えボタンが出ます。矢印キーで1mm移動、Shift＋矢印でサイズ変更、Ctrl併用で0.5mm。
ダブルクリックか Delete でその箱だけ自動配置に戻ります。用紙サイズを変えると箱の手動配置はリセットされます（自由テキストは新しい用紙のほぼ同じ位置に移ります）。

ページ分け

表記

テーマ

新刊の箱の枠線はアクセント色です。箱を1つだけ変えたいときは、プロパティパネルを表示して箱を選び「箱」の色を指定します。

箱のデザイン

種別ごとに変える（「全体と同じ」以外を選ぶと、その種別だけ変わります）
透過素材（「透過素材」を選んだ箱の枠になります。1つの箱だけ別の素材・背景画像にするときは頒布物タブの「箱の画像」で）
透過素材なし

透過素材は、四隅の形を保ったまま辺と中央だけを伸ばして箱に合わせます（9スライス）。素材の角の範囲は、素材の短い辺のうち何％を角として扱うか、角の大きさは箱に描く角の大きさ、素材の濃さを下げると素材が淡くなります（Illustrator では不透明度として入るので、あとから変えられます）。透過を活かすには PNG を使ってください。Illustrator 用スクリプトでは、素材を箱の大きさに引き伸ばして配置します。
配布素材を使うときは、同人誌・お品書きでの使用や加工が利用規約で認められているか確認してください。

背景のグラデーション

プレビュー・PNG・PSD は動き始めの絵（静止画）になります。動きは書き出しタブの「▶ 動きを確認」で見られ、「MP4を書き出す」で動画にできます（1周の秒数も書き出しタブで決めます）。
流れる：色が向きに沿って流れる　ゆらめく：色のかたまりがゆっくり円を描く　回る：グラデーションの向きが1周する
グラデーションは帯と箱の後ろにあります。もっと見せたいときは、下の「背景画像」の帯の濃さ・箱の濃さを下げます（背景画像がなくても効きます）。

背景画像

背景画像なし

画像は用紙全体に、はみ出す分を切り落として敷きます。画像の濃さを下げると淡くなり、帯・箱の濃さを下げると背景が透けて見えます。
動かし方を選ぶと、動画では画像を並べて流します。縞・チェック・水玉など柄がくり返している画像は、くり返しの単位を自動で見つけて、つなぎ目が出ないように並べます（1周でくり返し1つ分進みます）。写真など、くり返しのない画像は画像ごと並べるので、境目が見えます。

フォント

自由テキスト（好きな場所に置く文字）

追加した文字は用紙の中央あたりに出ます。プレビュー上でドラッグして好きな場所へ。矢印キー・目安線・揃えボタンも使えます。ダブルクリックで初期位置に戻ります。

文字サイズ（％）

ここでの設定はすべての頒布物に効きます（例：タイトル 120・価格 100・仕様 80）。1つの頒布物だけ変えたいときは、頒布物タブの各項目の「この頒布物の文字サイズ」か、プロパティパネルで指定します（ここの％との掛け算）。

文字の色と濃さ（種類ごと）

濃さは 100％で通常、下げると薄く（半透明に）なります。色を変えていない項目はテーマの色に従います。「戻」で色だけテーマ色に戻せます。
箱ごとに変えたいときは、プロパティパネルを表示して箱を選ぶと、その箱だけの文字サイズ（全体・要素ごと）・色・濃さ・表紙画像の大きさを指定できます。

プレビューに置いている箱の一覧です（2枚に分けているときは表示中のページ）。上にあるものほど前面に描かれます。行を押すと選択、⋮⋮ をドラッグすると重なり順の入れ替え、目のアイコンで表示／非表示、鍵のアイコンでロック（プレビューで選べない・動かせない）。PC ではマウスを乗せるとプレビューで強調します。

PNG

動画（SNS告知用・MP4）

デザインタブで「背景のグラデーション」をオンにするか、背景画像の「動かし方」を選ぶと使えます。

背景（グラデーション・背景画像）が動く動画（MP4・30fps・音声なし）を書き出します。長さは上の「1周の秒数」です。最後の絵が最初の絵につながるので、繰り返し再生してもつなぎ目が出ません。2枚構成のときは1枚ずつ書き出します。
Chrome・Edge で書き出せます（動画を作れないブラウザでは、その旨を表示します）。

PSD（Photoshop）

上の「解像度」の設定で、レイヤー分けした PSD を書き出します。チェックを入れた種類は要素ごとに1レイヤーになり、レイヤー名で見分けられます。
文字：サークル名、見出し、頒布物ごとのタイトル・仕様・説明・価格・バッジ、自由テキストなど　箱・図形：頒布物の箱、バッジの地、見出しの飾り、スペース枠、完売の幕　表紙画像：表紙ごと　背景・帯：背景色（またはグラデーション）、背景画像、ヘッダー帯、フッター帯、ライン
チェックを外した種類は「背景 / 装飾 / 画像 / テキスト / 最前面」にまとめます。文字は画像化（ラスター）されるので、移動や表示切替・色調整はできますが、打ち直すことはできません。
A3・350dpi など大きいサイズは数十秒かかることがあります。

Illustrator（編集可能データ）

  1. Illustrator で ファイル ＞ スクリプト ＞ その他のスクリプト… から .jsx を選ぶ
  2. 表紙画像の元ファイルがあるフォルダを選ぶ（リンク配置されます）
  3. 2枚に分けた場合は、1つのドキュメントにアートボードが2つ並びます
  4. 「背景 / 装飾 / 画像 / テキスト / 最前面」のレイヤーに分かれた新規ドキュメントができます。文字はすべて生きたテキストなので、そのまま調整して PDF 入稿や Photoshop での加工に回せます

フォント名を空欄にすると、系統に合わせて源ノ角・小塚・游・ヒラギノなどを順に探し、見つからなければ Illustrator の既定フォントになります。字幅が変わるので、はみ出しは Illustrator 側で微調整してください。

動きの確認

お品書きメーカーの使い方

基本の流れ頒布物箱の調整レイヤー元に戻す文字背景2枚に分けるレイアウトまとめて登録書き出し保存確認と調整・スマホ困ったとき

基本の流れ

  1. 基本情報タブでサークル名・スペース番号・イベント名などを入力（空欄の項目は表示されません）
  2. 頒布物タブの「＋ 追加」で頒布物を登録（種別はボタンの下の「追加するときの種別」で選べます）
  3. デザインタブで用紙・テーマ・フォントを選ぶ
  4. プレビュー上で箱の位置や大きさを微調整
  5. 文字タブで文字の大きさ・色・濃さを調整し、必要なら自由テキストを追加
  6. 書き出しタブで PNG / PSD / Illustrator 用スクリプトを出力

変更はすべてプレビュー（PC では右、スマホでは上）にすぐ反映されます。

頒布物の入力

種別初期は 新刊 / 準新刊 / セット / 既刊 / 委託 / グッズ。デザインタブの「種別」で、追加・名前の変更・色・並べ替え・削除ができ、その並び順で見出しが区切られます
価格数字は「¥500」形式に整形。0 は「無料」。文字を入れるとそのまま表示（例：応相談）
タイトル改行できます（Enter）。改行した位置で折り返し、長い行は自動でも折り返します。ふつうは2行までですが、2行に収まらず箱の価格の上に余白があれば、その余白に入るだけ行を増やします（仕様の1行は残し、説明文より優先）。それでも入りきらない分は「…」で省略
仕様・説明箱に余白がある分だけ表示されます
R18 / 残りわずか / 完売バッジで表示。完売は箱全体に重ねて表示
箱の画像その頒布物の箱だけに使う画像。選ぶと、デザインタブの「箱のデザイン」（全体・種別ごと）に関係なく、その箱はこの画像を使います。使い方は2種類：枠（9スライス）は透過素材（PNG 推奨）の四隅の形を保ったまま辺と中央を伸ばして枠にします。背景（箱いっぱいに敷く）は縦横比を保ったまま箱いっぱいに広げ、はみ出した分は切ります（模様や写真向き。9スライスだと継ぎ目が出る画像はこちら）。濃さ ％はその箱の画像だけの濃さで、下げると淡くなり上の文字が読みやすくなります（Illustrator では不透明度）。「素材の下に箱の色を塗る」（枠のときは角の範囲・角の大きさも）はデザインタブの透過素材の設定を使います。✕ で外すと元のデザインに戻ります。画像だけで並べる種別の箱には使われません
おまけセットの特典本など。おまけの名前かおまけの表紙を入れると、表紙の横に「＋おまけ」の札が付いた点線の枠で出します（表紙があれば表紙、なければ名前）。どの種別でも使えます
添え書き箱の中に目立つ札で出す短い文字（例：+特典！、+ペーパー）
委託元委託を受けた頒布物のサークル名・作家名。入れると「委託：〇〇」の小見出しで分かれ、委託の箱が目立ちます（デザインタブの「委託」で切り替え）
画像表紙画像（PNG / JPG / PSD・PSB）。1点につき100枚まで選べ、2枚以上は箱の中に並べます（並べ方は「横に並べる / 少し重ねる」）。並べる枚数が空欄（自動）なら箱に入るだけ並べ、数を入れるとその枚数だけ並べて、残りを「+6！」のような札で示します。段数は自動（表紙がいちばん大きくなる段数を1〜5段から選ぶ）か、1〜5段を指定します。画像が16枚以上になると一覧はたたまれ、「ほか N 枚も表示」で全部出せます。◀ で順番を前へ、✕ で外します。「表紙画像の大きさ ％」で、その箱の中での画像の大きさを 20〜200% で変えられます（プロパティパネルの「画」と同じ）。大きくできるのは箱に収まるところまでなので、もっと大きくしたいときは箱も広げてください。画像の大きさを変えたときに文字の大きさまで変わってほしくない場合は、デザインタブの「表紙画像の大きさを変えても文字の大きさを変えない」をオンにします
この頒布物の文字サイズ ％その頒布物だけ、タイトル / 価格 / 仕様 / 説明 の大きさを別々に 50〜200% で変えられます（例：タイトル 120・価格 100・仕様 80）。文字タブの「文字サイズ（％）」との掛け算です。プロパティパネルの「題・価・仕・説」と同じ
⋮⋮ をドラッグ種別の見出しの ⋮⋮ で種別まるごと（お品書きの見出しの順番）、頒布物の ⋮⋮ でその種別の中を並べ替え。指でも操作できます
↑ ↓ / 複製 / 削除その種別の中で1つずつ移動、複製・削除。種別をまたいで動かすときは「種別」を変えます
✕（一覧の各行の右端）項目を開かずに、その頒布物を削除。文字や画像が入っているときは確認します（追加したばかりの空の頒布物はすぐ消えます）。間違えたときは「戻す」で戻せます

箱をドラッグ移動（頒布物の箱と、種別の見出し）

角をドラッグ（四隅）縦横同時に伸縮

  • 箱が重なっているときは、選択中（青い点線）の箱が優先されます
  • 動かしていない箱は自動配置のまま。動かした箱は頒布物を増減しても位置が変わりません
  • 種別の中に動かした箱（大きさを変えた箱も含む）があると、見出し・小見出しの線はその種別の箱の右端までになります（箱を狭めても線だけ長く残りません）
  • デザインタブの「すべて自動配置に戻す」で一括リセット。用紙サイズを変えたときも箱はリセットされます（自由テキストは位置を保ちます）

  • ヘッダーとフッターは固定です

元に戻す／やり直し

「↶ 戻す」（画面下）／ Ctrl＋Z1 つ前の状態に戻す
「↷ やり直し」（画面下）／ Ctrl＋Y（Ctrl＋Shift＋Z）戻した操作をやり直す
  • 箱の移動・伸縮だけでなく、文字の入力、頒布物の追加・削除・並べ替え、テーマや用紙の変更、「新規」「サンプル」「開く」なども戻せます（最大 100 手）
  • 文字の入力は 1 文字ずつではなく、同じ欄への続けての入力をまとめて 1 手として戻します。ドラッグは 1 回分が 1 手です
  • 入力欄の中で Ctrl＋Z を押したときも、ツール全体の「元に戻す」になります
  • 履歴はページを開いている間だけです。再読み込みすると消えます

文字（文字タブ）

自由テキスト「＋ 文字を追加」で、好きな場所に置ける文字を追加。内容・大きさ（mm）・色・濃さ・太字・揃え・ページを指定し、プレビュー上でドラッグして配置します。改行もできます
文字サイズ（％）タイトル / 価格 / 仕様 / 説明 / サークル名 / 種別の見出し を、それぞれ別々に 50〜200% で調整（例：タイトル 120・価格 100・仕様 80）。すべての頒布物に効きます。「文字サイズをすべて100%に戻す」で初期値
文字の色と濃さサークル名・イベント名・スペース番号・見出し・バッジ・タイトル・仕様・説明・価格・フッター・SNS など、文字の種類ごとに色と濃さ（0〜100％）を指定。「戻」で色だけテーマ色に戻ります
箱ごとの文字プロパティパネルを表示して箱を選び、「字」（その箱の文字全体の％）・「題・価・仕・説」（タイトル・価格・仕様・説明それぞれの％）・「色」・「濃」（％）・「箱」（箱の色）・「画」（表紙画像の大きさ％）を指定。その箱だけに適用。要素ごとの％は頒布物タブの「この頒布物の文字サイズ」でも変えられます。「この箱の色・文字・画像の設定を戻す」で解除
  • 濃さは 100％が通常で、下げるほど薄く（半透明に）なります。種類ごとの濃さと箱ごとの濃さは掛け算です
  • 文字サイズは「文字タブの種類ごとの％ × 箱の『字』 × 箱の要素ごとの％」の掛け算になります（例：文字タブのタイトル 120％ で、ある箱だけタイトル 90％ にすると、その箱のタイトルは 108％）。大きくしすぎると箱からはみ出したりタイトルが省略されたりするので、箱を広げるか倍率を下げてください
  • 自由テキストは、ダブルクリックで初期位置（用紙中央あたり）に戻ります。用紙サイズを変えたときは、新しい用紙の中のほぼ同じ位置（左寄り・中央・右寄り、上・下の関係を保つ）に移ります

背景（グラデーション・画像）

  • デザインタブ「背景のグラデーション」の「背景をグラデーションにする」で、背景を 2〜4 色のグラデーションにできます。動き方（流れる / ゆらめく / 回る）・向き・色・濃さ（下げると背景色と混ざる）を選べます。動きの速さ（1周の秒数）は書き出しタブで決めます
  • プレビュー・PNG・PSD は動き始めの絵になります。動きは書き出しタブの「▶ 動きを確認」で見られ、「MP4を書き出す」で SNS 告知用の動画にできます
  • グラデーションは帯と箱の後ろにあります。もっと見せたいときは、下の帯の濃さ・箱の濃さを下げます（背景画像がなくても効きます）
  • デザインタブ「背景画像」の「画像を選ぶ」で、好きな画像（PNG / JPG / PSD）を用紙全体に敷けます。「外す」で解除
  • 画像の濃さ：下げると画像が淡くなり、文字が読みやすくなります
  • 帯の濃さ：下げるとヘッダー・フッターの帯が半透明になり、背景が透けます
  • 箱の濃さ：下げると頒布物の箱が半透明になります（枠線と文字はそのまま）
  • 画像は縦横比を保ったまま用紙を覆い、はみ出す分は切り落とされます
  • 動かし方（動画）：→ 横 / ↓ 縦 / ↘ / ↗ に流すを選ぶと、動画では画像を並べて流します（静止画は今までどおり）。縞・チェック・水玉など柄がくり返している画像は、くり返しの単位を自動で見つけて、つなぎ目が出ないように並べます。写真など、くり返しのない画像は画像ごと並べるので境目が見えます。縞に沿った向きなど、柄が変わらない向きを選ぶと動いて見えないので、注意が出たらほかの向きにしてください
  • Illustrator に書き出す場合は、背景画像のファイルも表紙画像と同じフォルダに置いてください

2枚に分ける

  1. デザインタブの「2枚に分ける」をオン
  2. 種別ごとに 1枚目 / 2枚目を選ぶ（初期値：新刊・準新刊・セットが1枚目、既刊・委託・グッズが2枚目。自分で追加した種別は1枚目）
  3. 例外にしたい頒布物は、その項目の「載せるページ」で個別に指定
  4. 画面左下の「1枚目 / 2枚目」でプレビューを切り替え

レイアウトの設定

最小列数1行に並べる箱の数の下限。窮屈なときは自動で列が増えます
段組本体を左右に分けるか。「自動」は横長の用紙で種別が3つ以上あると2段になります
種別ごとに見出しで分けるオフにすると見出しなしで登録順に並びます
種別「＋ 種別を追加」で自分の種別（例：ペーパー、無料配布）を作れます。名前の欄で名前を変更、色の四角でバッジと見出しの色を変更（「戻」でテーマの色）、↑↓で見出しの順番を入れ替え、「削除」で削除（その種別の頒布物は「既刊」に移ります）。初期の6種類を消した場合は「消した初期の種別を戻す」で戻せます。初期の「新刊」は名前を変えても、箱の枠の強調・「新刊を大きく」・新刊の列数がそのまま効きます
種別ごとの並べ方画像だけをオンにすると、その種別は表紙だけを縦長のまま並べ、価格は見出しの右のまとめ価格で示します（数字なら「ALL ¥500」、文字ならそのまま）。タイトルもで表紙の下にタイトルを出せます。表紙のない頒布物はタイトルの札で並び、完売は表紙に重ねて表示します。
上の種別の横に並べるをオンにすると、その種別を見出しごと1つ上の種別（このページに頒布物がある種別）の右に並べます。続けてオンにすると3つ以上も並びます。幅は箱の数で分けるので、並んだ箱は同じ幅になり、行の高さはいちばん高い種別に揃います。委託元ごとの小見出しも、その種別の列の中に入ります。段組を2段にしたときは、横に並べた種別は同じ段に入ります
委託委託元ごとに小見出しを付ける：委託元を入れた頒布物を「委託：〇〇」ごとに分けます。委託の箱を目立たせる：種別が「委託」の頒布物と委託元が入っている頒布物を、委託の色で縁取ります（委託以外の種別では「委託」バッジも付きます）
箱の大きさ均等：同じ種別の箱は同じ大きさ（今までどおり）。中身に合わせる：表紙の枚数と段数に合わせて箱の高さを変えます（表紙が多い箱は高く、横長の写真だけの箱は低く）。表紙の多い箱を広く：さらに、表紙の多い箱は何列か使って横にも広げます。どちらも用紙に収まるよう、ほかの箱の大きさを調整します
新刊を大きく新刊の行を約1.6倍の高さにします
表紙のまわりに枠を付けるすべての表紙画像のまわりに、表紙の枠の色・太さ（mm）の枠線を引きます。線は画像の外側に引くので、絵には掛かりません。白っぽい表紙が背景に溶け込むときにも便利です。画像だけで並べる種別の表紙にも付きます（おまけの表紙と「+N！」の札は除く）
表紙に影を付ける表紙の下にドロップシャドウを付けます。影の色・濃さ（％）、右下へのずれ（mm。0 なら真後ろで、まわりにぼんやり広がる）、ぼかし（mm。0 ならくっきり）を変えられます。枠を付けているときは枠ごと影になります。付く表紙は「表紙のまわりに枠を付ける」と同じです。Illustrator ではぼかし（ガウス）の効果を付けた半透明の四角形になります（効果を付けられない版では、ぼかし無しの影になるので、必要なら「効果」メニューから付けてください）
表紙画像の大きさを変えても文字の大きさを変えないオフ（初期値）：表紙画像の大きさ（％）を変えると、残りの場所に収まるよう文字の大きさも自動で変わります。オン：文字は表紙が100％のときの大きさのまま、画像だけが大きく・小さくなります（文字の位置は画像に合わせて動きます）。入りきらない文字は省略されたり価格と重なったりするので、そのときは箱を広げてください
色を上書きするテーマの帯色とアクセント色を好きな色に変更
箱の色を上書きするすべての箱の色と、枠線・区切り線の色を変更（新刊の枠線はアクセント色）。箱を1つだけ変えるときは、プロパティパネルで箱を選んで「箱」の色を指定
箱のデザイン標準・角なし・影付き・二重線・見出し帯・左ライン・角飾り・点線・透過素材から選択。「種別ごとに変える」でその種別の箱だけ変えられます。1つの箱だけ別の素材や背景画像にしたいときは、頒布物タブの「箱の画像」で選びます。透過素材・箱の画像の箱に影を付けるをオンにすると、透過素材や箱の画像を使っている箱に、箱の形のドロップシャドウを付けます（色・濃さ・右下へのずれ・ぼかしを指定。影は箱の外側にだけ出るので、素材の透けている所から影が見えることはありません。Illustrator ではぼかしの効果を付けた半透明の四角形として箱の下に入ります。「素材の下に箱の色を塗る」をオフにしていると、透けた所から影が見えるので、必要なら手で直してください）。透過素材は四隅の形を保ったまま伸ばして箱に合わせます（Illustrator では引き伸ばして配置。素材ファイルも表紙画像と同じフォルダへ）
PC内のフォント名インストール済みフォントの名前を入れるとプレビューと PNG に使われます

まとめて登録

  • 画像からまとめて追加：表紙画像を複数選ぶと、ファイル名をタイトルにして一括登録。種別はボタンの下の「追加するときの種別」で選べます（初期値は新刊）
  • CSV読込：列は「種別, タイトル, 価格, 仕様, 説明, R18, 完売, 残りわずか, 画像ファイル名, 委託元, 添え書き, おまけ, おまけ画像」（委託元から後ろは省略可）。画像が複数あるときはファイル名を「|」で区切ります（例：vol1.png|vol2.png。100枚まで）。画像は、読み込み済みの同じファイル名の画像が使われます。フラグ列は 1 や ○ でオン。種別は名前で書きます。一覧に無い名前はその名前の種別として自動で追加され、空欄は「既刊」になります
  • CSV保存：出力したファイルがそのままひな形になります

書き出し

PNG印刷用は 350dpi / 300dpi、SNS 用は「Web / SNS用（長辺2048px）」。2枚構成では2ファイル出ます
動画（MP4）背景（グラデーション・流す背景画像）が動く動画（H.264・30fps・音声なし）。大きさは短辺1080px（SNS用）か720px（軽い）。長さは「1周の秒数」（2〜30秒）で、最後と最初がつながるので繰り返し再生してもつなぎ目が出ません。「▶ 動きを確認」で先に動きを見られます。Chrome・Edge で使えます
PSDPNG と同じ解像度設定で、レイヤー分けした PSD を出力。「要素ごとに別レイヤーにするもの」で 文字 / 箱・図形 / 表紙画像 / 背景・帯 を選ぶと、選んだ種類は要素1つずつが別レイヤーになります（外した種類は 背景 / 装飾 / 画像 / テキスト / 最前面 にまとめる）。文字は画像化されます（移動は可、打ち直し不可）
Illustrator用 .jsxIllustrator の「ファイル ＞ スクリプト ＞ その他のスクリプト…」で実行 → 表紙画像のフォルダを選択 → レイヤー分けされた編集可能なドキュメントができます
  • Illustrator では表紙画像を元ファイル名で探してリンク配置します。画像は1つのフォルダにまとめ、名前を変えないでください
  • フォントを確実に指定したいときは、書き出しタブで PostScript 名を入力します
  • ブラウザと Illustrator では字幅が少し変わります。はみ出しは Illustrator 側で微調整してください

保存と読込

  • 入力内容はブラウザに自動保存されます。画像はブラウザ内のデータベース（IndexedDB）に入れるので、表紙が多くても画像ごと残ります（どちらもこの端末のブラウザの中だけで、外部には送信しません）
  • 自動保存はブラウザごとに別で、サイトデータを削除すると消えます。Safari では、しばらく開いていないサイトの保存データが消されることがあります
  • 確実に残すには右上の「プロジェクト保存」で JSON にし、「開く」で読み込みます
  • 「新規」は2回押すと全消去、「サンプル」は見本データに置き換えます

確認モードと調整モード（スマホでの使い方）

右上の「確認」入力パネルを隠してプレビューを画面いっぱいに表示します。うっかり箱を動かさないよう、確認モードでは箱を動かせません
「調整に戻る」（または Esc）入力パネルを戻して、編集できる状態に戻ります
境目のつまみ（スマホ）プレビューと入力パネルの間のつまみを上下にドラッグして比率を変えます。初期値はプレビュー 1：入力パネル 3。ダブルタップで 1:3 に戻ります

モードと境目の位置は、この端末のブラウザに記憶されます（プロジェクトの JSON には入りません）。
